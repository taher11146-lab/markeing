# دليل نسق النسق العربي القوي لحملات التسويق
## Arabic Copy-Strength Guide — كتابة نص عربي يعكس قوة الحملات

> الغاية: صياغة نص عربي لا ينقصه هدوء ولا يلجأ إلى الترجمة الناشطة، بل يعكس
> **قوة الحملة، حركة المبيعات، وثقة الإعلان** — بلغة عربية راقية ومقننة.

---

## 1. القاعدة ذات الأولوية — افتح بفعل فعل نشط

| بدلاً من | استخدم |
| --- | --- |
| نحن نقود منشأتك عبر… | **ندأل هيمنتك** / **ندفع موجتك** / **توجّه مسرحاً نموذجياً** |
| نبنئ… | **بناء…** (مصدر فعل مباشر) |

**مفتاح**: لا تبدأ ب "نحن نـ" / "سنـ" / "قد". ابدأ بفعل الفاعل المطلق أو صيغة الأمر.

---

## 2. استبدل الحشو بالطاقة الحركية

| كلمة ضعيفة | بدائل قوية |
|---|---|
| مرنة / متكاملة / تتكامل | **تحتكر** (تسيطر)، **تخضع** (تتحكم)، **تُعاد صياغتها** |
| حلول | **محركات**، **مؤشرات**، **محركات نمو** |
| ندفع الولاء | **ندفع المبيعات** — الأرقام لا تكذب |

---

## 3. إيقاع العرض — فعل + نتيجة + حجة

> **نص: نتيجة | حجة**
>
> "حملاتنا تُعيد تعريف العوامل، ليس للكشف بل للتحويل."

- كرّر الفعل القوي في كل فقرة (النمو / التحويل / السيطرة / التفوق).
- أنهِ بحجة رقمية أو إثبات ملموس.

---

## 4. العبارات المفتوحة — استبدالات مباشرة

| النص الضعيف | الاستبدال القوي |
|---|---|
| ننطلق إعلانات عشوائية | **تبني حملاتًا تُعيد تعريف العوامل** |
| نمو لانهائي | **نمو لا يُقاوم** |
| نظام رقمي متكامل | **نظام أداء لاشيء يتوقّف** |
| تكنولوجيا مؤتمتة | **أتمتة تُعيد ضخ النتائج** |
| تفوق في السوق الدولي | **تفوقك تُعيد رسم الخريطة** |
| تصميم حلول راقية | **محركات نمو راقية** |

---

## 5. تجنّب — لا تُقع في الفخ

- لا تُضع الكلمة الإنجليزية داخل الجملة (Merchandise/Funnels/Performance)؛ استبدلها: "بضاعة"، "مسارات بيع"، "أداء".
- لا تبالغ ب "نحن" / "شركاؤنا" — ركّز على **العميل والنتيجة**.
- لا تستخدم صفات مطاطية: "آمنة جداً"، "عالية الجودة". استبدلها بفعل: "تحمي"، "تفوق".

---

## 6. شذر من الأسلوب — الاستمرارية الفعلية

- 8Ps لكلّ حرف P: كنّها **محركات**، لا "عناصر".
- كل كرت: **<فعل> + <نتيجة> + <دليل/وسيلة>**.

### مثال كرت:
**المنتج** — "ندوّر محركات بصرية تُباع قبل ما تُصمّر." — تصميم موحد يضاعف معدل التحويل.
